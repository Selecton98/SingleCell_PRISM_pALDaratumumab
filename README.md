# SingleCell_PRISM_Daratumumab

This is the code accompanying the following publications by Xuezhu (Sunny) Wang and Xinyi Xiong

- Single-Cell Analysis Reveals Inflammatory–Immunosuppressive Niches in Daratumumab-Resistant Primary AL Amyloidosis (https://www.medrxiv.org/content/10.64898/2026.03.28.26349317v1) [Preprint]
- Single-cell analysis of plasma cell–centered inflammatory–immunosuppressive niches and response to daratumumab in primary light-chain amyloidosis (J Clin Oncol 44, 2026 suppl 16; abstr 7553)
- Single–cell analysis of BCR and transcriptome uncovers plasma cell clonal dynamics and immune exhaustion linked to daratumumab response in primary light–chain amyloidosis (Blood 146, 2025 2158-2159)
- MM-913: Defining Gene Expression Programs of Amyloidogenic Clonal Plasma Cells Characterized by Single-Cell B-Cell Receptor and Transcriptomic Profiling (Clinical Lymphoma Myeloma and Leukemia 25, 2025 suppl 1; page S951) [Prelim analysis]
